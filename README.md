# 交互式 iPhone 模拟器

使用 HTML、CSS 和 JavaScript 制作，可以直接在网页浏览器中运行。不需要安装项目依赖，也不需要数据库。

## 在 GitHub Codespaces 中预览

1. 在 Codespaces 打开 `phoneme` 仓库。
2. 如果之前的 Port 3000 网页仍在运行，只需要刷新预览页面。
3. 如果没有运行：点击顶部菜单 **Terminal（终端） → New Terminal（新建终端）**。
4. 确认终端在 `phoneme` 文件夹中，然后粘贴下面的命令并按回车：

   ```sh
   python3 -m http.server 3000 --bind 0.0.0.0
   ```

5. 点击底部的 **PORTS（端口）** 标签，找到 **3000**，点击这一行的 **Open in Browser（在浏览器中打开）** 图标。
6. 修改文件后刷新浏览器即可。如果仍显示旧页面，请按 `Ctrl + Shift + R`（Mac：`Command + Shift + R`）。

如果提示 `Address already in use`，说明 3000 端口已经有服务在运行，先打开原来的预览。如果原服务不属于本项目，在原终端按 `Ctrl + C` 停止后，再从本项目文件夹运行命令。不要关闭不确定用途的服务。

## 文件说明

- `index.html`：手机外框、主屏幕和网页结构。
- `style.css`：外观、不同屏幕大小的布局、深浅色主题。
- `script.js`：应用交互和浏览器本地保存。
- `README.md`：说明和预览步骤。

## 第一版功能

- iPhone 风格圆角外框、状态栏、Wi-Fi、信号、电池、灵动岛、Dock 和底部返回横条。
- 点击图标打开应用，点击底部横条或按 `Escape` 返回主屏幕。
- 设置：切换深浅色主题、修改手机名称、选择四款壁纸。刷新后保留。
- 信息：示例聊天、输入并发送消息，刷新后保留已发送消息。
- 计算器：加、减、乘、除、百分比、正负号、删除和清空。
- 备忘录：新建、编辑、自动保存、删除；删除前会询问确认。
- 照片：十二张生成的风景示例图，三列图库、放大查看、搜索和收藏。
- 天气：模拟天气和小时预报，不连接真实天气 API。
- 保留日历、时钟、地图、App Store、健康、钱包、电话、Safari、音乐等已有模拟应用。
- 点击手机顶部的灵动岛锁屏；锁屏后点击“轻点解锁”。

## 保存和模拟范围

备忘录、消息、手机名称、主题和壁纸保存在当前浏览器的本地存储中。清除网站数据会删除这些记录；不同浏览器或预览网址之间不会自动同步。浏览器禁止本地存储时，只能保留当前打开期间的内容。

相机、地图、健康、钱包、天气和拨号为模拟体验，不拍摄真实照片、不定位、不支付、不拨打真实电话。音乐播放浏览器合成和弦，Safari 搜索会在新标签页打开 Bing。页面不需要外部字体或图片服务。

## 第二版：主屏幕分页与微信

- 移除手机外的品牌、介绍文字和控制面板，只显示手机。壁纸仍可以在设置中更改。
- 主屏幕图标使用内嵌 SVG 绘制，参照 iOS 默认图标的颜色和形状；并非苹果官方图标资源。
- 左右滑动或鼠标拖动翻页，也可以点击 Dock 上方的圆点；聚焦主屏幕后可以使用左右方向键。
- 第二页包含微信和计算器。Dock 保留电话、Safari、信息和音乐。
- 微信支持微信列表、通讯录、发现、我四个页面；点击文件传输助手可发送文字，刷新后保留。朋友圈可点赞。
- 微信是本地模拟应用，不支持登录、真实联系人或发送真实微信消息。
- 点击顶部灵动岛锁屏，点击底部横条返回主屏幕。

## 第三版：原生应用样式与 Fitness

- 根据参考截图细化时钟、地图、健康、计算器图标的形状、层次和颜色；保留全部应用入口。
- 设置改为 iOS 分组列表：手机名称在「通用 → 关于本机」，主题与亮度在「显示与亮度」，壁纸在「墙纸」。原有设置值和存储键保留。
- 信息采用绿色消息气泡；备忘录采用黄色操作色；计算器采用黑色界面与橙色运算键；照片和天气同步调整为系统应用风格。
- 第二页新增 Fitness：活动（粉红）、锻炼（绿色）、站立（青色）运动环。
- Fitness 可切换日期、查看最近七天、记录某一天的累计活动量、修改每日目标。记录和目标刷新后保留。
- 首次打开今天会显示示例运动量；其他未记录日期为零。所有数据为本地模拟，不读取 Apple Health，也不连接真实 iPhone。
- 运动环达到目标时显示完整一圈；超过目标的实际数值仍会显示。步数与距离为基于活动量的演示估算。


## 第四版：信息、世界时钟与真实风景图库

- 重新绘制信息、时钟、设置、相机、照片、备忘录和健康图标，增加镜头细节、时钟数字和金属齿轮层次。HTML 中的资源版本标记帮助浏览器刷新图标。
- 信息首页为联系人列表，包含小A、哈尼、妈妈、周末出游和文件传输助手。每个联系人有虚构日常对话，可以独立发送、搜索、置顶与查看未读消息。旧版已发消息迁入文件传输助手，原始存储不会删除。
- 世界时钟显示北京、芝加哥、纽约、匹兹堡、厦门和伦敦的实时时间。使用浏览器的 IANA 时区规则自动处理夏令时，并显示相对浏览器当地时间的时差与日期。可切换12/24小时制及调整城市顺序。
- 时钟同时包含模拟闹钟列表、秒表和计时器。闹钟列表不会在后台响铃；计时器在打开的计时器页面提示结束。
- 照片采用三列图库，包含12张原创生成的 Windows 壁纸风格风景示例图。支持年月浏览、搜索、放大、前后切换、收藏和多选收藏。收藏保存在浏览器中。
- `assets/landscapes.png` 是内嵌图库使用的本地图片素材，必须和其它项目文件一起保留。它以3列4行图集存放12张示例图，由网页展示各个区域，不依赖外部图片网站。
- 照片不会访问你的电脑相册；之后可以再添加你提供的照片。
